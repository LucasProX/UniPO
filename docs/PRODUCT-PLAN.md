## 1. 一页纸

**一句话**：UniPO 把「大学四年怎么读」变成一张可执行的成长地图——首页让你每天来，成就系统让你四年离不开，工具箱让你有理由装它。

**名字**：UniPO = **Uni**versity + **PO**st。PO 不只是一条帖子，也可以是一条经验、一条避坑、一条通知、一条「这个阶段该做什么」的攻略。**帖子是砖，路径是图纸。**

**要解决的问题**：大学里最折磨人的不是没信息，是「不知道自己不知道」。四六级要早考、教务处在哪、这个专业毕业能干嘛、同届的人已经在投简历了——这些信息一直存在，但不平等地分布在少数人手里。

**目标用户**：以大一新生为切口，逐步覆盖在校本科生；供给端是校/院/年级运营、金V（班长/学委/社团负责人）、学校官方。

**核心资产**：结构化的成长路径库（通用主线 + 学校/专业支线）、可验证的运营组织、以及用户进度数据。

**商业模式（后置）**：先免费做留存；稳定后推会员（本地工具不限次、云存储、批量处理），第一年不做支付。

**当前阶段**：单校、单专业、单年级验证「一张路径图能不能让人少走弯路」，再复制。

## 2. 背景与机会

### 2.1 真实痛点

- **信息不平等**：有人有学长学姐、有消息灵通的室友；有人没有。同一个学校，同一届，信息差可以决定保研、实习、转专业的结果。
- **官方渠道失效**：通知发在 QQ 群，和接龙、表情包混在一起；学校官方 App 又丑又难用，平时不会打开。
- **现有产品难用**：表白墙、二手小程序、校园墙，难看的难看、难用的难用；内容碎片化，没有结构。
- **成长路径缺失**：没有人告诉新生「大一该干嘛、大二该准备什么、大四的 Boss 是什么」，全靠自己撞。

### 2.2 机会

- 大学生是**高密度、高同质、强地域**的人群，单校打透的成本远低于泛人群产品。
- 校园信息有**强时效、强本地、强身份**属性，通用平台（抖音/小红书）很难做到「同校同专业可执行」。
- 学校/社团有**发布活动、认证身份、触达学生**的刚需，可以成为供给端合作方。

### 2.3 不做什么

- 不做「校园版抖音」：不靠泛娱乐内容竞争。
- 不做「万能工具箱」：只做高频、纯本地、和校园场景强相关的工具。
- 不做「又一个表白墙」：表白墙可以作为频道，但不能定义品牌。
- 第一年不做支付、不做云存储、不做二手交易。

## 3. 用户与场景

| 角色 | 核心诉求 | 产品承接 |
|---|---|---|
| 大一新生 | 报到、军训、选课、社团、四级，什么都想知道 | 阶段卡、入学清单、新生攻略、课表 |
| 在校生 | 找搭子、避坑、经验、二手、吐槽 | 信息流、频道、私信、关注 |
| 高年级/求职 | 实习、秋招、考研/考公时间线 | 阶段节点、简历工具、经验贴 |
| 班长/学委/社团负责人 | 发通知、收报名、组织活动 | 金V、附件、活动徽章 |
| 学校/学院/社团 | 官方通知、活动发布、学生触达 | 运营后台、活动徽章、数据 |
| 平台运营 | 内容审核、活动管理、金V审核 | 管理后台、审计日志 |

### 关键场景（按时间）

1. **开学前**：报到材料、军训准备、宿舍/校园地图。
2. **开学 1 个月**：选课、社团面试、四级报名、校园卡/网费。
3. **学期中**：考试、竞赛、志愿服务、转专业/辅修。
4. **大二/大三**：实习、科研、交换、证书。
5. **大四**：秋招、考研、考公、毕业论文——最终 Boss。

## 4. 产品定位

### 4.1 对外一句话

> **UniPO：大学四年的成长路线图。**
> 备选：**大学的每一步，都有过来人写好的攻略。**

「校园信息流」是功能，「成长路线图」是定位。功能可以多，定位只能一个。

### 4.2 用户感知策略：渐进披露

不要求用户一进来就理解「路径」，而是让他先因为「有用/好玩」留下，再慢慢发现核心：

- 第一屏：信息流 + **阶段卡**（你当前在第几周、这周该做什么）。
- 第一次打开：选学校/专业/年级，生成「你的阶段清单」。
- 帖子与路径双向绑定：帖子打阶段标签，路径节点聚合帖子。
- 个人主页：进度、徽章、称号可视化。
- 底部导航：保留「成就」入口（不叫「路径」）。

**原则**：核心可以被慢慢发现，但入口必须被设计出来，不能靠运气。

### 4.3 竞品与替代方案

| 替代品 | 优势 | 不足 | 我们的差异 |
|---|---|---|---|
| 小红书 / 抖音 | 内容丰富、算法强 | 非本地、非结构化、真伪难辨 | 同校同专业、按阶段组织、来源可验证 |
| 校园墙 / 表白墙 | 强活跃、低门槛 | 碎片化、审核风险、无成长价值 | 把流量频道化，核心是路径与工具 |
| 学校官方 App | 权威、有通知 | 难用、更新慢、学生不打开 | 体验好、聚合官方+学生内容 |
| 超级课程表 / 工具类 | 高频、刚需 | 工具孤岛、无内容与成长 | 工具作为入口，路径与社区承接 |
| 学长学姐 / 群聊 | 可信、即时 | 不可规模化、信息沉底 | 把隐性知识结构化、可检索、可复用 |

**为什么能赢**：不是内容更多，而是**结构更好、来源更可信、和你的阶段更相关**。

## 5. 产品结构

### 5.1 四层结构

```
入口层     首页信息流 / 阶段卡 / 课表 / 工具箱 / 搜索
习惯层     发帖、评论、点赞、关注、私信、频道、活动
资产层     成就系统（章节 / 任务 / 徽章 / 称号）、经验库、金币
基础层     金V认证、校/院/年级运营、审核、审计、附件与内容安全
```

### 5.2 首页

- 顶部：**阶段卡**（当前阶段、3 个待办、进度、进入成就系统/课表）。
- 信息流：推荐 / 校 PO / 院 PO / 专业 PO；支持频道（表白墙、吐槽、找搭子、二手）。
- 左栏：推荐热榜、签到。
- 右栏：事件日历、运营公告。
- 大屏轮播：运营位（已支持后台配置，预留算法位）。

### 5.3 成就系统（核心）

- **章节**：大一上/大一下/大二上/……/大四下，按专业可定制。
- **任务**：每个章节 3–8 个可执行任务，带截止时间、材料、过来人提醒。
- **进度**：完成度、连续记录、阶段通关。
- **关联**：任务下聚合经验贴、官方通知、相关工具。
- **不做**：强迫式每日任务、排行榜内卷、付费加速。

### 5.4 工具箱

首发 5 个纯本地工具：

| 工具 | 场景 | 实现 |
|---|---|---|
| 图片/多图 → PDF | 报名材料、作业、证明 | 浏览器本地 |
| PDF 合并 / 拆分 / 删页 / 旋转 | 材料整理、论文附件 | 浏览器本地 |
| PDF 压缩 | 教务系统上传限制 | 浏览器本地 |
| 图片格式转换（HEIC/PNG/JPG/WebP） | iPhone 照片、交材料 | 浏览器本地 |
| 证件照尺寸 / 换底色 | 报名、考试、简历 | 浏览器本地 |

**配额**：每个工具每月免费 5 次；金币可兑换额外次数；会员（后续）不限次。

**入口策略**：不靠「工具列表」被发现，而是场景化入口——发帖要传材料、上传失败、报名截止时出现。

### 5.5 社交

- 关注/粉丝、私信、会话、在线状态。
- 后续：续火花、找搭子、频道。
- 治理：拉黑、举报、移除粉丝、审核、审计。
- 原则：社交是留存层，不是品牌；表白墙单独频道、单独规则。

### 5.6 多端策略

| 端 | 角色 | 认证 | 当前状态 |
|---|---|---|---|
| **iOS** | 主战场：留存、通知、相机、Keychain | Bearer + Keychain（手机号验证码登录） | ✅ 登录页 / 首页 / 帖子详情 / 私信 / 工具 / 成就 / 发 PO |
| **Web** | 分享落地页、SEO、兜底、管理后台 | httpOnly Cookie + CSRF | ✅ 信息流 / 社交 / 轮播 / 后台 |
| 未来 Android | 复制 iOS 的 `/api/v1` 契约 | Bearer + Keystore | 规划中 |

**iOS 设计基线**：最低 iOS 17，iOS 26 SDK；Liquid Glass Dock（iOS 26+），旧系统退化材质；黑白蓝设计 tokens；成就页承担游戏化动效。
详见 [`ios/README.md`](ios/README.md)。

### 5.7 管理后台

- 概览、内容审核、轮播运营、用户与权限、报表、监控、审计。
- 后续：活动管理、徽章发放、金V审核、金币流水、举报队列、附件审核。

## 6. 核心机制

### 6.1 阶段卡

首页常驻卡片，展示：

- 当前阶段（如「大一上 · 第 3 周」）；
- 3 个待办（带截止时间/材料/地点）；
- 进度（已完成/总数）；
- 入口：成就系统、课表、相关攻略。

**价值**：不打扰信息流，却让核心路径一直被看见。

### 6.2 徽章与稀有度

| 等级 | 来源 | 供给规则 |
|---|---|---|
| 普通 | 阶段任务、签到、首次发帖 | 人人可得，不设上限 |
| 稀有 | 连续打卡、优质内容被采纳、活动参与 | 有门槛，不限量 |
| 史诗 | 学期目标、比赛入围、志愿服务时长 | 每学期少量 |
| 传说 | 年度冠军、特殊贡献、校史级事件 | **硬上限**，一年少量 |
| 限定 | 任意等级 + 时间窗（迎新、校庆） | 过期不补 |

**限定是「可获得性」标签，不是第五档难度。** UI 用边框/角标区分。

### 6.3 称号

- 与徽章同分级；**同一时间只展示一个**。
- 传说称号带赛季/有效期，到期转「荣誉陈列」。
- 称号必须绑定**可验证的事**（比赛名次、志愿时长、认证身份），不卖、不随机。

### 6.4 金币经济

**原则**：金币纯免费、不充值、不过期；第一年不做交易。

**来源**（有每日上限与质量权重）：

- 签到（基础）；
- 有效互动（被点赞/评论/收藏/采纳，而非「发了就给」）；
- 完成阶段任务；
- 参加校园活动；
- 优质内容被运营采纳。

**消耗**：

- 工具超额次数；
- 头像框、主页背景、称号展示位；
- 补签卡等趣味道具；
- **不卖**曝光、排序、等级、成就。

**约束**：

- 不过期，但余额上限（如 5000），防止囤币套利；
- 每日获取上限，防止刷帖；
- 不做盲盒/抽奖（未成年人与合规风险）。

### 6.5 附件与内容安全

**权限矩阵**：

| 账号类型 | 可带附件 | 限制 |
|---|---|---|
| 普通用户 | ❌ | 只能发图片（走媒体库校验） |
| 金V（班长/学委/社团负责人/教师） | ✅ 图片 + PDF | 单文件 ≤ 10MB，每帖 ≤ 3 个，**先审后发** |
| 院级/校级运营、学校官方 | ✅ PDF/Office | 单文件 ≤ 20MB，带官方标识与审计 |

**下载**：附件下载需登录；公开可预览、不可匿名下载。

**安全要求**：

- 类型白名单：先只收 PDF/JPG/PNG；不收 Office/压缩包/HTML/SVG/可执行文件。
- 不信任扩展名和 Content-Type，走 magic bytes（现有 `ImageSignature`）。
- PDF 拒绝 JavaScript/嵌入文件；必要时转图片预览。
- MinIO 私有桶、短时效签名 URL、`Content-Disposition: attachment`、`nosniff`。
- 上传者、帖子、hash、审核人、下架记录全部进审计。
- 附件可单独举报/下架；每日上传配额。

### 6.6 金V 与运营体系

**组织**：

- 平台内容组：主线模板、审核标准、质量问题；
- 校运营：本校本地化、金V初审、活动、拉新；
- 院/年级运营：专业支线、金V推荐、答疑。

**金V 审核链**：

1. 申请人提交学生证/班级群截图/辅导员证明（三选一，仅用于审核）；
2. 校运营初审 → 院级复核 → 平台抽审；
3. 记录审核人、时间、依据，进审计；
4. 每学年复核，换届自动失效；
5. 可举报、可撤销；**不可售卖**。

**隐私边界**：认证材料不公开；前台只展示「金V + 身份标签」。

### 6.7 内容供给模型

- **主线**（平台官方写）：通用阶段、关键节点、方法论；版本化。
- **支线**（校/院运营、学长学姐写）：本校/本专业差异；按模板填。
- **模板字段**：阶段、适用学校/专业、关键时间点、行动清单、常见坑、参考资料、最后更新时间、来源（官方/运营/学生）。
- **审核**：主线平台审；支线校运营审、平台抽审。
- **保鲜**：过期自动标记「待更新」，每年至少复核一次。

## 7. 冷启动与增长

### 7.1 冷启动原则

1. **供给先于拉新**：没有内容平台是空着上线的。
2. **单机价值先于网络效应**：阶段卡 + 工具 + 课表，没人发帖也有用。
3. **单校、单专业、单年级**打透，再复制。
4. **先做 100 个种子用户，再做 1000**。

### 7.2 渠道

- 校级学生会**外联部**合作（付费地推/内容共创，按交付验收）；
- 班级群、新生群、社团群；
- 校园大使（1 校 1 人，现金 + 认证 + 后续实习机会）；
- 争取团委/学工老师知情或支持，避免「未经许可的商业活动」。

### 7.3 0–90 天节奏

**第 0–3 周：备货**

- 选 1 所学校 + 1 个专业（信息差大：医学/法学/计算机/师范）；
- 找 5–10 个该专业大二/大三学生，按模板写「大一到大二」路径，按篇付钱；
- 收 50 条本地内容（通知、社团、选课、食堂/自习室、军训避坑）；
- 做「新生 30 天清单」落地页（Web 优先）。

**第 3–6 周：首发**

- 通过学生会/班级群发「新生入学路径」，不推下载；
- 目标：300–500 注册，100 个完整看完路径；
- 建种子群，创始人亲自访谈前 100 个用户。

**第 6–12 周：转起来**

- 每周 3 条运营内容 + 2 条学生投稿；
- 给投稿人金V/经验值/署名；
- 观察 D7 留存、阶段完成率、发帖人数/DAU。

### 7.4 首批目标（单校）

| 指标 | 目标 |
|---|---|
| 注册 | 500 |
| 阶段卡点击率 | ≥ 40% |
| 完成首个阶段任务 | ≥ 30% |
| D7 留存 | ≥ 30% |
| 预置内容 | 100 条 |
| 金V | 10 个 |
| 学生投稿 | 30 篇 |

## 8. 运营组织

### 8.1 三层，但按规模逐步建

- **平台内容组**（创始人 + 1–2 人）：主线、标准、审核。
- **校运营**（学生会对接人/校园大使）：本地化、金V初审、活动。
- **院/年级运营**（学长学姐/班长）：专业支线、金V推荐。

**第一所学校**：创始人兼平台内容组，校运营 1 人，院级暂不设。

### 8.2 激励与治理

- 现金（按交付）、认证身份、活动资源、实习内推（后期）；
- 账号归平台，内容归平台，数据归平台；
- 学期级合作框架 + 交接文档，避免换届归零；
- 明确 KPI：注册、内容篇数、活动场次、金V 数。

## 9. 商业化（后置）

### 9.1 节奏

- 第一年：不支付、不云存储、不交易；只做留存与内容。
- 第二年：会员内测；云存储按成本定价。
- 第三年：校园会员、机构合作、二手交易（单独评估）。

### 9.2 会员设计（草案）

- 价格：**9.9 元/月**；
- 权益：本地工具不限次、云存储 5–10GB、批量处理、OCR、专属头像框、去广告；
- **先不做自动续费**，用学期卡/手动续费，降低学生群体「忘记取消」的负面口碑；
- 免费层保留：每月 5 次/工具、基础徽章、社区功能。

### 9.3 成本约束

- 本地工具边际成本接近 0；
- 云存储是重成本，先算每 GB 成本再定容量；
- 服务端工具（OCR/扫描增强）放会员或按次付费。

## 10. 指标体系

### 10.1 北极星

**每周完成至少一个阶段任务的用户数（Weekly Active Progressors）**。

它同时衡量：留存、路径价值、内容有效性。

### 10.2 分层指标

| 层级 | 指标 |
|---|---|
| 获客 | 注册、渠道转化、首日激活 |
| 激活 | 首次会话触达阶段卡比例、完成首个任务比例 |
| 留存 | D1/D7/D30、周回访 |
| 内容 | 人均浏览、发帖/评论率、优质内容率、供给覆盖 |
| 成就 | 阶段完成率、徽章获得率、称号展示率 |
| 工具 | 使用次数、免费额度耗尽率、金币兑换率 |
| 活动 | 参与人数、徽章发放、复参率 |
| 治理 | 举报处理时长、下架率、金V 复核率 |

### 10.3 关键实验

- 阶段卡位置/文案对点击率的影响；
- 清单式 onboarding vs 自由浏览；
- 金币奖励「发帖」vs「有效互动」对内容质量的影响；
- 活动徽章对复参率的提升。

## 11. 路线图

### Phase 0（现在–6 周）：单机价值 MVP

- 阶段卡（单校单专业，大一上）；
- 成就系统第一版：章节、任务、进度、徽章（普通/稀有/史诗）；
- 5 个本地工具 + 每月 5 次配额；
- 金币账本（赚/花/余额，不过期、有上限）；
- 金V 附件（PDF，先审后发，下载需登录）；
- 后台：活动/徽章/金V/附件审核的最小闭环；
- 预置 100 条内容。

### Phase 1（6–12 周）：单校验证

- 1 所学校、1 个专业、500 注册；
- 活动徽章 + 学校/社团合作 1–3 场；
- 金V 审核链跑通；
- 指标：D7 ≥ 30%，阶段完成率 ≥ 30%。

### Phase 2（3–6 个月）：复制

- 第二专业、第二学校；
- 内容模板化、运营手册、校园大使；
- 工具箱扩展到 8–10 个；
- 会员内测（不支付）。

### Phase 3（6–12 个月）：商业化与多端

- 3–5 所学校；
- 会员/云存储灰度；
- iOS 原生 App（复用 `/api/v1`）；
- 二手交易单独评估。

## 12. 风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| 徽章通胀 | 徽章太多、无人珍惜 | 宁少勿多；硬上限；每年盘点 |
| 金币通胀/刷帖 | 为币发垃圾内容 | 质量权重、每日上限、有效互动才给 |
| 内容过期 | 路径写一次就旧 | 年份/版本标签、年度复核、待更新标记 |
| 学校关系 | 被认定未经许可 | 团委/学工知情，合作框架，合规推广 |
| 运营换届 | 人走茶凉 | 组织级合作、账号归平台、交接文档 |
| 附件安全 | 钓鱼/木马/违规内容 | 白名单、扫描、审核、审计、下架 |
| 金V 冒充 | 身份造假 | 证据链、复核、撤销、不可售卖 |
| 单人产能 | 什么都想做 | 单校单专业，先证明再复制 |
| 商业化过早 | 留存未稳就收费 | 第一年不支付 |
