# 校园活动与成长奖励规划

日期：2026 年 10 月 23 日。产品负责人确认：成长系统以「认证组织者发布的官方活动」为奖励来源；内容只限同校，同校所有公开经验帖对本校用户可见；后续加入校园社团与二手交易。本文是活动闭环的功能、界面、数据与分期依据，任务状态在开发规划书和小任务路线图中维护。

## 1 规则

- **内容范围**：只限同校。「同级 / 专业 / 全校」是筛选视角，不做访问限制。
- **奖励来源**：只有认证组织者发布的活动在签到后发放经验与金币。用户自定义任务可记录、提醒、完成，但不给经验和金币。
- **发布权限**：试点期为校级、院级、专业运营与管理员；金 V 与社团负责人在 A3 之后通过申请与审核开放。组织者只能面向自己权限内的范围发布：校级运营面向全校，院级运营面向本院，专业运营面向本专业，管理员不受范围限制但仍限本校。
- **奖励上限**（单场）：管理员与校级运营 100 经验、200 金币；院级运营 50 经验、100 金币；专业运营 30 经验、60 金币。超出上限由服务端拒绝，不静默截断。
- **金币先只攒不花**：A2 交付获取与流水，商城和用途另行评审。金币不充值、不交易、不过期，有每日获取上限。

## 2 活动闭环

状态：草稿 → 待审核（仅金 V、社团）→ 报名中 → 报名截止 → 进行中 → 已结束；任意阶段可取消。状态由时间与人工动作共同决定，服务端统一计算后返回，客户端不自行推断。

| 环节 | 规则 |
| --- | --- |
| 发布 | 标题、封面、类型、开始与结束时间、地点、简介、报名须知、面向范围（学校、学院、专业，可选入学年份）、名额、是否候补、报名截止时间、奖励 |
| 报名 | 一键报名与取消；满员进候补，取消时按报名先后递补；同一人对同一活动只有一条报名记录；不在面向范围内的人不能报名 |
| 提醒 | 报名成功、活动前 24 小时与 1 小时、变更与取消、奖励到账；进消息「互动」，真机推送待付费开发者账号 |
| 签到 | 组织者端动态二维码（30 秒轮换、服务端签名）与 4 位签到码（只在签到窗内有效）；组织者可手动补签；只有已报名者能签到，每人每场一次，接口幂等 |
| 发奖 | 签到成功即发经验与金币，并自动完成对应成长清单项（系统事件，不可由用户撤回）；组织者 24 小时内可撤销作弊签到，奖励同步扣回 |
| 历史 | 参与者保留签到时间与奖励，汇总为成长档案；组织者查看报名数、签到率与名单 |
| 沉淀 | 活动结束后可发带活动标签的经验帖，挂在活动详情下 |

## 3 iOS 界面

- 首页：阶段卡下方「本周活动」横向卡片；板块筛选为「推荐 · 同级 · 专业 · 全校」。
- 活动列表：「推荐 / 本周 / 我报名的」。
- 活动详情：主办方与认证标识、时间地点、名额进度、奖励、须知、已报名头像；底部主按钮随状态变化（报名、已报名可取消、候补中、待通过、已截止、去签到、已签到）。
- 签到页：扫码或输入签到码，成功后显示奖励。
- 成长页：「本学期清单」合并已报名活动、官方必做与自定义任务；「成长档案」按学期归档参加过的活动与徽章。
- 我的：金币余额与流水，「我的活动」分即将参加与历史；组织者工具（发布、名单与审核、签到大屏、手动补签、变更取消、数据）只对有权限的账号显示，不新增管理网页。

## 4 后端

新增 `activity` 模块（活动、报名、签到、组织者权限）与 `wallet` 模块（金币账本，按发奖幂等键入账，余额由流水决定）；后续 `organization` 模块承接学院、学生会与社团。经验复用 `ExperienceService`。迁移从 V27 起。
