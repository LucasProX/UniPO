# 主页、关系与评论交互记录

日期：2026-10-21。范围：原生 iOS、后端资料契约和独立测试实例。

## 本轮实现

| 用户操作 | 实际行为 |
| --- | --- |
| 打开帖子准备评论 | 纸白卡片、品牌蓝图标与焦点描边；随输入展开，最多 1000 个 UTF-16 单元 |
| 发送评论失败 | 保留输入和原页面，可重试；发送中禁用重复提交 |
| 点击帖子、评论或会话的头像 | 通过统一入口打开该 UID 对应的主页；本人进入自己的主页 |
| 查看他人主页 | 读取公开资料与作品，提供关注和私信入口 |
| 仅自己关注对方 | 按钮显示“已关注” |
| 双方都关注 | 按钮显示“朋友”及双向箭头 |
| 更换主页背景 | 相册选图、压缩、上传并保存到资料；其他访问者读取同一背景字段 |
| 恢复默认背景 | 将空字符串提交为清除操作，后端持久化为 NULL |
| 切换作品、喜欢、收藏 | 胶囊滑块、方向过渡与横向滑动；开启 Reduce Motion 时减少动效 |

本人主页保留原头像编辑入口；公开主页本轮只展示作品。现有 Web 页面不新增功能，仅同步 OpenAPI 类型以保持兼容契约。

## 当前验证边界

新版启动后模拟器处于未登录状态，已请用户完成登录和协议确认。本人三标签、背景相册保存、登录后的关注按钮及会话头像入口仍需继续在模拟器逐项核对；接口断言和编译结果不替代这些交互验收。

## 部署和复验

本轮只更新 `unipo-test-backend`，V19 迁移仅作用于 `unipo_test`；生产容器保持原镜像与健康状态。测试服务通过现有 SSH 隧道暴露在 Mac 回环 18081，连接方式见 [TEST-ENVIRONMENT.md](TEST-ENVIRONMENT.md)。更新前已保存独立测试库备份与旧测试镜像；不修改或清除生产数据。

```bash
swift test --package-path ios/Packages/UniPOCore
python3 scripts/smoke-social-profile.py
# TEST_PEER_PUBLIC_UID 为独立测试账号的公开 UID
ADMIN_UID=$TEST_PEER_PUBLIC_UID bash scripts/smoke.sh http://127.0.0.1:18081
```

后两条命令会在独立测试库创建普通账号、图片、帖子、评论或消息，不输出凭据。社交主页脚本只允许连接回环测试端口；通用冒烟必须显式指定上面的回环地址与专用测试接收账号。
