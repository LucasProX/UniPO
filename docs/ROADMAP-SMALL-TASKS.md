# UniPO 小任务路线图

版本：1.0  
日期：2026 年 10 月 23 日  
范围：原生 iOS、后端和基础设施

## 1 使用方式

此前“完善整个 UniPO 并完成校园试点”的长期目标覆盖工程、产品、设计、内容、运营和发布，无法作为一次连续开发任务可靠执行。该大目标已暂停。本文件把它拆成可独立领取、实现、验证和提交的小任务。

每次只选择一个任务。任务完成必须留下代码或文档、对应验证证据、已知限制和下一任务建议。未完成的任务不以“总体仍在推进”代替验收，也不因为排期到达自动开始试点。

本期继续遵守以下边界：Web 用户端、网页分享、课表和新增管理网页暂缓；现有兼容代码保留。管理和运营能力通过受控 API、命令行工具和操作手册交付。

## 2 当前基线

截至 2026 年 10 月 23 日，身份撤销、拉黑关系串行、互动幂等、消息 Outbox、分设备推送进度、消息游标分页、断线增量补齐和 iOS 显式发送重试均已有代码与本机验证证据。DP15 详情见 [DP15 验收记录](DP15-VERIFICATION.md)，Outbox 操作见 [消息投递失败查询与受控重试](OUTBOX-OPERATIONS.md)。

这些结果证明当前源码在受控环境中的对应行为，不代表生产服务器已部署，也不代表 iOS 17、真机、真实 APNs、HTTPS 或校园试点已经验收。

## 3 第一组 先交付当前消息改动

| 编号 | 小任务 | 交付内容 | 验收条件 |
| --- | --- | --- | --- |
| M01 | 提交 DP15 源码与文档 | V25、后端分页和幂等、iOS 分页和失败重试、Outbox 运维工具、验收记录 | 提交推送到主仓库；工作区无本任务未提交文件 |
| M02 | 部署独立 test 后端 | 更新服务器 test 实例及独立测试库，执行 V25 | readiness 正常；迁移到 V25；生产实例和生产库未被修改 |
| M03 | 模拟器消息人工验收 | 登录两个测试账号，验证长会话、加载历史、失败重试、前后台切换 | 无漏消息或重复消息；失败消息可重试或放弃；历史加载不强制跳到底部 |
| M04 | 最低系统与真机消息验收 | iOS 17 运行、真机签名、弱网和锁屏恢复 | 主要操作可达；换号不泄漏旧会话或草稿；结果写入 DP15 记录 |
| M05 | 真实通知验收 | 配置 sandbox APNs，验证设备换绑、退出和推送归属 | 真实设备收到属于当前账号的提醒；退出后旧设备不再接收；不宣称已读回执 |
| M06 | 消息容量基线 | 代表性会话量、长历史和并发发送压测 | 记录机器规格、数据量、吞吐、P95、错误率和慢 SQL；据实决定索引或分页调整 |

M01 完成后，后续任务分别领取。M02 至 M06 互不合并成一个长期任务。

M01 状态（2026 年 10 月 23 日）：提交前补齐了漏生成的前端 OpenAPI 类型，并复跑冒烟、后端打包、iOS Core 与模拟器构建，结果见 DP15 记录；本地提交完成，推送到主仓库后视为完成。

## 4 第二组 发布和恢复底线

| 编号 | 小任务 | 交付内容 | 验收条件 |

| R01 | Release HTTPS 地址 | 正式域名、证书、Release API 配置与 ATS 收口 | Release 不使用公网明文 HTTP；证书链和 API 健康检查通过 |
| R02 | 正式登录通道 | 正式短信或经批准的替代身份流程 | 生产不接受任意验证码；限流和失败提示可用；测试配置与生产隔离 |
| R03 | 数据库备份脚本 | MySQL 定时备份、校验和、保留和恢复说明 | 在隔离库恢复成功，抽查用户、帖子、任务和消息 |
| R04 | 媒体备份恢复 | MinIO 对象与数据库引用联合备份 | 隔离恢复后图片可读取，缺失对象可被发现 |
| R05 | 最小告警 | HTTP 5xx、数据库、Redis、Outbox、磁盘和备份告警 | 人为制造可恢复故障后，告警到达指定值班入口并记录恢复过程 |
| R06 | 发布清单 | 版本、迁移、配置、备份、回滚和负责人模板 | 一次 test 环境演练按清单执行，步骤和结果可追溯 |

## 5 第三组 成长闭环

| 编号 | 小任务 | 交付内容 | 验收条件 |
| --- | --- | --- | --- |
| G01 | 确定首条成长主线样本 | 一所学校、一个专业、一个年级的校历、任务、来源和负责人 | 每个任务有适用范围、期限、来源、复核日期和负责人 |
| G02 | 成长背景与校历契约 | 学校、专业、入学年份或阶段及校历 API | 修改背景后匹配结果可解释；旧完成记录保留；隐私规则由服务端执行 |
| G03 | iOS 成长背景引导 | 首次选择、保存失败恢复和后续修正 | 输入失败不丢失；重新进入与服务端一致；无匹配状态有明确说明 |
| G04 | 动态阶段摘要 | 服务端当前阶段摘要与 iOS 首页阶段卡 | 不再出现固定周数或固定百分比；访客、待引导、无匹配、完成和失败状态齐全 |
| G05 | 任务详情与完成撤回 | 任务来源、期限、版本、完成和撤回 API 与 iOS 页面 | 重复请求幂等；完成后重进仍一致；撤回只影响当前任务事实 |
| G06 | 攻略关联和有效期 | 任务关联 PO、来源、过期和下架规则 | 过期内容不继续作为有效攻略；运营可用受控工具更新 |
| G07 | 图片转 PDF（2026-10-23 暂停） | iOS 本地选图、排序、生成、预览和导出 | 暂停：工具页本期不需要，入口随导航重排移除；恢复时重新评审 |

## 7.5 核心功能优先（2026-10-23 起）

产品负责人确定：工具页暂不需要，本期重点是成长系统、PO 流与社交，以及全 App 的界面设计。以下任务优先于第二组之后的默认顺序；后端已具备、iOS 未接的能力先补界面。

| 编号 | 小任务 | 交付内容 | 验收条件 |
| --- | --- | --- | --- |
| C01 | 导航重排 | 移除工具 Tab；底栏为首页、成长、发布、消息、我的 | 未登录点消息或我的先登录；推送进入会话不受影响 |
| C02 | 成长背景与阶段推算 | 入学年份字段；引导选择学校、学院、专业、入学年份；按入学年份与日期推算当前阶段 | 不同入学年份看到对应阶段；缺背景时明确提示补充；旧用户不被虚构背景 |
| C03 | 首页下一步与任务撤回 | 首页阶段卡显示当前阶段下一项任务并可完成；任务可撤回且经验同步回退 | 重复完成或撤回幂等；撤回后进度与经验一致 |
| C04 | 互动通知 | 消息页内的点赞、收藏、评论、回复通知列表 | 拉黑用户不出现；点进对应帖子 |
| C05 | 评论回复与评论点赞 | 详情页回复某条评论、评论点赞 | 回复带父评论；点赞幂等；失败可恢复 |
| C06 | 帖子菜单 | 分享、删除自己的帖子、举报帖子作者 | 删除后从列表消失；举报有原因选择与受理提示 |
| C07 | 关注与粉丝列表 | 主页统计可进入关注、粉丝列表并可关注或回关 | 关系状态以服务端为准；朋友为双向关注 |
| C08 | 多图与标签发帖 | 最多 9 张图、可删可排序、标签输入 | 上传失败不丢已填内容；重复点击不重复发帖 |
| C09 | 设计 token 与动态字体 | 语义字体随 Dynamic Type 缩放，统一圆角、空态与错误态组件 | 大字体下主要页面可读可操作 |

C01 至 C08 状态（2026 年 10 月 23 日）：源码已完成，后端打包 337 项发现、零失败（127 项隔离专项按条件跳过），空库迁移到 V26、42 项冒烟与成长接口 HTTP 实测通过，iOS Core 115/115，模拟器在本机新后端上检查了首页阶段卡、成长页、消息与互动、帖子详情菜单和楼中楼回复。服务器 test 实例尚未部署 V26；发帖多图、关注列表、举报提交和分享面板未在模拟器逐项点验，iOS 17 与真机未验。C09 未开始。

## 8 领取顺序

默认顺序（2026-10-23 调整）为 C01 至 C09 优先，穿插 R03 备份；随后 M02、M03、R01、R02、R04、R05、G01、G05、G06、O01 至 D03、P01 至 P05。G07 暂停。真实 APNs、iOS 17 和容量任务可在设备与账号具备时穿插，但每次仍只领取一个任务。

下一次开始开发时，应直接说任务编号，例如“继续 M02”。任务结束后更新本文件状态或对应验收记录，再选择下一项。
